# 09. GenomeReport

## Objective

Generate the final interactive report for an RSV genomic analysis.

This step integrates the annotated RSV-A and RSV-B metadata, updates lineage classifications using the Nextclade results generated during Step 05, creates a final combined master table, and generates the GenomeReport.

Optionally, annotated phylogenetic figures generated during Step 08 can be incorporated into the report.

## Input

Step 09 requires an analysis directory:

```bash id="ck5b6h"
bash workflow/09_genome_report/run.sh ANALYSIS_DIR [PHYLOGENY ...]
```

One or more phylogenetic figures can optionally be provided after `ANALYSIS_DIR`.

### Clustered metadata

The main metadata inputs are generated during Step 07:

```text id="oc8e54"
ANALYSIS_DIR/
└── 07_dataset_annotation/
    ├── RSV-A/
    │   └── RSV-A_master_table_clustered.tsv
    │
    └── RSV-B/
        └── RSV-B_master_table_clustered.tsv
```

### Nextclade results

Nextclade lineage classifications are obtained from the results generated during Step 05:

```text id="7czd2b"
ANALYSIS_DIR/
└── 05_reference_alignment/
    ├── RSV-A/
    │   └── nextclade.tsv
    │
    └── RSV-B/
        └── nextclade.tsv
```

### Optional phylogenetic figures

Annotated phylogenetic figures generated during Step 08 can optionally be supplied to GenomeReport.

For example:

```text id="qvgb6n"
ANALYSIS_DIR/08_phylogeny/RSV-A/figures/RSV-A_fasttree_circular.png
ANALYSIS_DIR/08_phylogeny/RSV-B/figures/RSV-B_fasttree_circular.png
```

Step 08 is not required to generate GenomeReport.

## Processing

### 1. Normalize Nextclade results

The Nextclade output generated during Step 05 is normalized using:

```text id="6l4rlj"
scripts/sequence_qc/normalize_nextclade_table.py
```

For each RSV subtype:

```text id="p06qct"
nextclade.tsv
      │
      ▼
normalize_nextclade_table.py
      │
      ▼
nextclade_normalized.tsv
```

The normalized table contains the Nextclade information required for metadata annotation.

### 2. Update lineage classifications

GenomeTableTools is used to annotate the clustered master tables with the Nextclade lineage classification.

For RSV-A:

```text id="avzcgc"
RSV-A_master_table_clustered.tsv
              +
RSV-A/nextclade_normalized.tsv
              │
              ▼
    GenomeTableTools annotate
              │
              ▼
    RSV-A_master_table.tsv
```

The same process is performed independently for RSV-B.

The Nextclade field:

```text id="m4is5o"
nextclade_lineage
```

is renamed to:

```text id="ax4e7h"
Lineage
```

and replaces the existing `Lineage` value in the clustered metadata table.

### 3. Merge RSV-A and RSV-B

The updated subtype-specific tables are concatenated using GenomeTableTools:

```text id="c7mw23"
RSV-A_master_table.tsv
          +
RSV-B_master_table.tsv
          │
          ▼
GenomeTableTools concat
          │
          ▼
master_table_final.tsv
```

`master_table_final.tsv` is the final combined metadata table used as input for GenomeReport.

### 4. Generate GenomeReport

GenomeReport is generated from:

```text id="wzbxoq"
master_table_final.tsv
```

If no phylogenetic figures are provided:

```text id="rph1q5"
master_table_final.tsv
          │
          ▼
     GenomeReport
          │
          ▼
interactive report
```

If phylogenetic figures are provided:

```text id="y0vsj5"
master_table_final.tsv
          +
phylogenetic figures
          │
          ▼
     GenomeReport
          │
          ▼
interactive report
with phylogenies
```

## Output

Results are written under:

```text id="qnkcxg"
ANALYSIS_DIR/09_genome_report/
```

The directory contains the final combined metadata table:

```text id="rwv0an"

```

together with the report files, tables, and figures generated by GenomeReport.

Intermediate subtype-specific metadata tables are also generated:

```text id="15syh4"

RSV-B_master_table.tsv
```

The exact report output structure is determined by GenomeReport.

## Software

This step uses:

- GenomeTableTools
- GenomeReport
- `scripts/sequence_qc/normalize_nextclade_table.py`

`normalize_nextclade_table.py` prepares the Nextclade results for metadata integration.

GenomeTableTools updates the subtype-specific metadata with the Nextclade lineage classifications and combines RSV-A and RSV-B into the final master table.

GenomeReport generates the final interactive genomic surveillance report.

## Notes

Step 09 is the final step of the core analysis pipeline.

Phylogenetic reconstruction is optional. GenomeReport can be generated immediately after Step 07 without executing Step 08.

If phylogenetic reconstruction is subsequently performed, Step 09 can be rerun with one or more phylogenetic figures to incorporate them into the report.

The final report is generated from `master_table_final.tsv`, which combines RSV-A and RSV-B after updating their lineage classifications with the Nextclade results.

The raw master-table GenomeReport is a separate workflow and should not be confused with Step 09. The raw report is generated directly from the unfiltered Step 01 master table and does not perform the downstream annotation and integration procedures described here.
