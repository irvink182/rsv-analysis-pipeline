# 07. Dataset annotation

## Objective

Integrate genomic cluster assignments with the master metadata table and generate annotation files for downstream phylogenetic visualization and reporting.

This step produces two main metadata products for each RSV subtype:

- a clustered master table containing epidemiological metadata and genomic cluster assignments;
- a lightweight phylogeny metadata table used by phyloannot to generate annotation files for phylogenetic visualization.

The annotation workflow supports two modes:

- **national** — uses curated annotation configurations for national surveillance;
- **custom** — generates an annotation configuration from the selected custom dataset.

## Input

Step 07 requires two arguments:

```bash
bash workflow/07_dataset_annotation/run.sh ANALYSIS_DIR MODE
```

where `MODE` must be:

```text
national
```

or:

```text
custom
```

### Master metadata

The complete master metadata table generated during Step 01 is used as the metadata source:

```text
results/01_master_table/master_table.tsv
```

### Genomic cluster annotations

Cluster assignments are read from the Step 06 results for the corresponding analysis:

```text
ANALYSIS_DIR/
└── 06_clustering/
    ├── RSV-A/
    │   └── tables/
    │       └── cluster_annotations.tsv
    │
    └── RSV-B/
        └── tables/
            └── cluster_annotations.tsv
```

## Processing

RSV-A and RSV-B are processed independently using the same general workflow.

### 1. Integrate cluster assignments and metadata

The script:

```text
scripts/clustering/cluster_metadata.py
```

combines the genomic cluster assignments generated during Step 06 with the master metadata table.

For RSV-A, this generates:

```text
RSV-A_master_table_clustered.tsv
RSV-A_phylogeny_metadata.tsv
```

For RSV-B:

```text
RSV-B_master_table_clustered.tsv
RSV-B_phylogeny_metadata.tsv
```

The clustered master table contains the metadata required for downstream reporting, while the phylogeny metadata table contains the variables required for phylogenetic annotation.

### 2. Initialize the phyloannot configuration

For each RSV subtype, phyloannot first generates an annotation configuration based on the available phylogeny metadata:

```text
*_phylogeny_metadata.tsv
        │
        ▼
phyloannot --init-config
        │
        ▼
annotation_config.tsv
```

### 3. Select the annotation mode

The annotation configuration depends on the analysis mode.

#### National surveillance

For `MODE=national`, curated subtype-specific configurations are used:

```text
resources/phyloannot/
├── RSV-A_annotation_config.tsv
└── RSV-B_annotation_config.tsv
```

These configurations provide standardized annotations for the national surveillance analysis.

#### Custom analysis

For `MODE=custom`, the configuration generated by `phyloannot --init-config` from the custom dataset is used:

```text
ANALYSIS_DIR/07_dataset_annotation/RSV-A/phyloannot/annotation_config.tsv
ANALYSIS_DIR/07_dataset_annotation/RSV-B/phyloannot/annotation_config.tsv
```

This allows the available metadata categories to adapt to the selected custom dataset.

### 4. Generate phylogenetic annotation files

phyloannot generates annotation files for:

- iTOL
- Microreact
- ggtree

Geographical information is mapped using:

```text
autonomous_community
```

together with:

```text
resources/locations/spanish_communities.tsv
```

No phylogenetic tree is required during this step.

## Output

Outputs are written under:

```text
ANALYSIS_DIR/07_dataset_annotation/
```

with the following general structure:

```text
ANALYSIS_DIR/
└── 07_dataset_annotation/
    ├── RSV-A/
    │   ├── RSV-A_master_table_clustered.tsv
    │   ├── RSV-A_phylogeny_metadata.tsv
    │   └── phyloannot/
    │       ├── annotation_config.tsv
    │       ├── itol/
    │       ├── microreact/
    │       └── ggtree/
    │
    └── RSV-B/
        ├── RSV-B_master_table_clustered.tsv
        ├── RSV-B_phylogeny_metadata.tsv
        └── phyloannot/
            ├── annotation_config.tsv
            ├── itol/
            ├── microreact/
            └── ggtree/
```

### `*_master_table_clustered.tsv`

Contains the metadata associated with the sequences included in the clustering analysis together with their genomic cluster assignments.

This table is subsequently used to construct the final metadata table for GenomeReport.

### `*_phylogeny_metadata.tsv`

Lightweight metadata table containing the variables required for phylogenetic annotation.

This table is used by phyloannot and by the phylogenetic visualization workflow.

### `phyloannot/`

Contains the annotation configuration and ready-to-use annotation files for iTOL, Microreact, and ggtree.

## Software

This step uses:

- `scripts/clustering/cluster_metadata.py`
- phyloannot

`cluster_metadata.py` integrates genomic cluster assignments with the corresponding metadata.

phyloannot prepares annotation files for phylogenetic visualization.

## Run

### National surveillance

```bash
bash workflow/07_dataset_annotation/run.sh \
    results/national_surveillance \

```

### Custom analysis

```bash
bash workflow/07_dataset_annotation/run.sh \

```

## Next steps

After Step 07, two downstream workflows are available.

### Generate GenomeReport

GenomeReport can be generated directly without phylogenetic reconstruction:

```bash
bash workflow/09_genome_report/run.sh ANALYSIS_DIR
```

This is the default behavior of the national and custom pipeline launchers.

### Optional phylogenetic analysis

Phylogenetic reconstruction can be performed using FastTree:

```bash
bash workflow/08_phylogeny/run.sh \
    ANALYSIS_DIR \
    MODE \
    fasttree
```

or IQ-TREE:

```bash
bash workflow/08_phylogeny/run.sh \
    ANALYSIS_DIR \
    MODE \
    iqtree
```

After phylogenetic reconstruction, GenomeReport can be regenerated including the resulting phylogenetic figures.

## Notes

Step 07 does not require a phylogenetic tree. It prepares the metadata and annotation files required for subsequent phylogenetic visualization.

Genomic clusters are calculated during Step 06. This step only integrates those cluster assignments with the corresponding metadata.

The clustering analysis contains assignments at **5-, 10-, and 20-SNP thresholds**. The **5-SNP cluster (`Cluster_5`)** is the clustering level used for phylogenetic tree annotation.

National and custom analyses use different annotation strategies: national surveillance uses curated annotation templates to maintain consistent visualization across analyses, while custom analyses use a configuration generated from the metadata available in the selected dataset.
