# 05. Reference-guided alignment

## Objective

Generate reference-guided whole-genome alignments for RSV-A and RSV-B using Nextclade.

Quality-controlled sequences are aligned independently against their corresponding reference genomes. The resulting alignments provide a common genomic coordinate system for SNP extraction, genetic distance calculation, genomic clustering, and phylogenetic inference.

The reference genome is explicitly included in each alignment and is retained as a taxon for downstream analyses.

## Input

Step 05 requires an analysis directory:

```bash
bash workflow/05_reference_alignment/run.sh ANALYSIS_DIR
```

### Quality-controlled sequences

The main sequence inputs are generated during Step 04:

```text
ANALYSIS_DIR/
└── 04_sequence_qc/
    ├── RSV-A/
    │   └── analysis.qc.fasta
    │
    └── RSV-B/
        └── analysis.qc.fasta
```

### Reference genomes

Subtype-specific reference genomes are stored under:

```text
resources/references/
├── RSV-A_reference.fasta
└── RSV-B_reference.fasta
```

### Nextclade datasets

Local Nextclade datasets are stored under:

```text
resources/nextclade/
├── rsv_a/
└── rsv_b/
```

## Processing

RSV-A and RSV-B are processed independently using the same workflow.

### 1. Add the reference genome

The corresponding reference genome is concatenated with the quality-controlled analysis sequences:

```text
reference.fasta
      +
analysis.qc.fasta
      │
      ▼
alignment_input.fasta
```

This explicitly includes the reference genome in the dataset before alignment.

### 2. Reference-guided alignment

Nextclade is used to generate the reference-guided whole-genome alignment:

```text
alignment_input.fasta
        │
        ▼
     Nextclade
        │
        ├── alignment.fasta
        └── nextclade.tsv
```

The resulting `alignment.fasta` preserves the genomic coordinate system defined by the corresponding RSV reference genome.

### 3. Alignment validation

The alignment is evaluated using:

```text
scripts/sequence_qc/check_fasta.py
```

The script compares the aligned sequences against the corresponding reference and generates:

```text
fasta_summary.tsv
```

### 4. SNP extraction

SNP-sites is applied to the complete reference-guided alignment to generate an alignment containing only variable positions:

```text
alignment.fasta
      │
      ▼
   SNP-sites
      │
      ▼
alignment.snps.fasta
```

### 5. Constant-site counts

SNP-sites is also used with the `-C` option to calculate constant-site information from the complete alignment:

```text
alignment.fasta
      │
      ▼
 SNP-sites -C
      │
      ▼
constant_sites.txt
```

This information can be used by downstream phylogenetic analyses based on SNP-only alignments.

## Workflow

```text
reference.fasta
      +
analysis.qc.fasta
      │
      ▼
alignment_input.fasta
      │
      ▼
   Nextclade
      │
      ▼
alignment.fasta
      │
      ├───────────────┬─────────────────┐
      │               │                 │
      ▼               ▼                 ▼
check_fasta.py    SNP-sites        SNP-sites -C
      │               │                 │
      ▼               ▼                 ▼
fasta_summary.tsv  alignment.snps.fasta  constant_sites.txt
```

The same workflow is performed independently for RSV-A and RSV-B.

## Output

Outputs are written under:

```text
ANALYSIS_DIR/05_reference_alignment/
```

with the following structure:

```text
ANALYSIS_DIR/
└── 05_reference_alignment/
    ├── RSV-A/
    │   ├── alignment_input.fasta
    │   ├── alignment.fasta
    │   ├── nextclade.tsv
    │   ├── fasta_summary.tsv
    │   ├── alignment.snps.fasta
    │   └── constant_sites.txt
    │
    └── RSV-B/
        ├── alignment_input.fasta
        ├── alignment.fasta
        ├── nextclade.tsv
        ├── fasta_summary.tsv
        ├── alignment.snps.fasta
        └── constant_sites.txt
```

### `alignment_input.fasta`

Contains the quality-controlled analysis sequences together with the corresponding reference genome.

### `alignment.fasta`

Complete reference-guided whole-genome alignment generated by Nextclade.

### `nextclade.tsv`

Nextclade output generated during the alignment step.

### `fasta_summary.tsv`

Summary generated by `check_fasta.py` for validation of the aligned sequences.

### `alignment.snps.fasta`

SNP-only alignment containing variable positions extracted from the complete alignment.

### `constant_sites.txt`

Constant-site information calculated from the complete alignment.

## Software

This step uses:

- Nextclade
- SNP-sites
- `scripts/sequence_qc/check_fasta.py`

Nextclade generates the reference-guided whole-genome alignment.

`check_fasta.py` validates the resulting aligned sequences against the corresponding reference genome.

SNP-sites extracts variable positions and calculates constant-site information from the alignment.

## Notes

The reference genome is explicitly added to `alignment_input.fasta` before running Nextclade and is therefore retained in the resulting alignment.

The reference-guided alignment preserves a common genomic coordinate system and is used throughout the remainder of the pipeline for SNP-based genomic analyses and phylogenetic reconstruction.

RSV-A and RSV-B use independent reference genomes and Nextclade datasets and are therefore aligned and analysed separately.
